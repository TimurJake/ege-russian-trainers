# ЕГЭ 2026 · Тренажёры по русскому языку

Интерактивные тренажёры для подготовки к заданиям ЕГЭ по русскому языку.
Написаны на чистом HTML, CSS и JavaScript — без сборщиков, фреймворков и зависимостей.

> **Демо:** замени ссылку на свою после публикации на GitHub Pages —
> `https://ТВОЙ-НИК.github.io/ТВОЙ-РЕПОЗИТОРИЙ/`

## Тренажёры

| Задание | Тема | Что внутри |
|---|---|---|
| **4** | Ударения | Орфоэпический минимум (~230 слов), теория по частям речи, режимы 30/60/90/все/бесконечный, статистика |
| **15** | Н и НН | Правописание Н/НН во всех частях речи, теория с правилами и исключениями, работа над ошибками, статистика |

## Возможности

- **Режимы тренировки:** фиксированная длина (30 / 60 / 90), весь словник, бесконечный режим.
- **Работа над ошибками:** после завершения сессии можно прогнать только те задания, где были ошибки.
- **Статистика:** сохраняется в `localStorage` — общие счётчики, точность, лучшая серия, топ проблемных заданий, история последних 20 сессий.
- **Теория:** встроенный справочник для каждого тренажёра, отдельная кнопка выхода наверх и вниз.
- **Адаптивный дизайн:** сайдбар переезжает наверх на узких экранах, всё работает на телефоне.
- **Тёмная тема:** минималистичная чёрно-серая палитра с мягкими анимациями.
